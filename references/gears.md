## 二、渐开线外齿轮（行星减速器用）

### 2.1 齿条刀具包络法（不是圆弧拼接）

| 齿廓段 | 生成方式 | 几何意义 |
|---|---|---|
| 渐开线段 | θ(ρ)=sT/(2r)+inv(αt)−inv(αy) | 齿条直刃展成的共轭曲线 |
| 齿根过渡 | 刀尖圆角在展成运动中的**包络（摆线）** | 真实齿根 |
| 齿根平底 | 刀具顶刃展成的圆弧 | 齿根圆上一小段真圆弧 |
| 齿顶 | 齿顶圆圆弧 | 被齿顶圆截断 |

关键公式（外齿）：
```
a0 = π·m/4 − x·m·tan α            刀具分度线半齿厚
h  = (ha* + c* − x)·m             刀尖高出分度线
rc = ρ*·m（受平顶限制）           刀尖圆角半径
Cy = h − rc
Cx = a0 − Cy·tan α − rc/cos α     圆角中心（刀具系）

展成：刀具平移 u，齿轮转 φ = u/r
包络点 P = Cw + rc·Cw/|Cw|，Cw = (Cx+u, Cy)
```

**根切不是特殊分支**：扫描时若摆线点 ρ>rb 且 θ_摆线<θ_渐开线，齿廓在该处截断，
渐开线从截断半径重新开始。这是包络的自然结果。

### 2.2 内齿圈

渐开线 + 与齿根相切的过渡圆弧（二分求切点）。
齿顶圆必须在基圆之外，门槛 `z > 2ha*/(1−cos αt)` ≈ 34。

### 2.3 验收

| 项 | 判据 |
|---|---|
| 左右对称 | 角偏差 <1e-15 rad |
| 分度圆半齿角 | 实测 = ψ = sT/(2r) |
| 根切判定 | zmin=2ha*/sin²αt，与实测一致 |
| 自交 | shapely `is_simple` |

## 三、谐波柔轮摆线齿廓（CTP，论文级）

### 3.1 算法来源

**Yao et al. "A Novel Cycloid Tooth Profile for Harmonic Drive with Fully Conjugate Features."**
*Actuators* 2025, 14, 187. DOI **10.3390/act14040187**

参考实现：`scar8969/drive.magic` 的 `js/ctp-revB.js`（clean-room，含 7 项实测修正）。
**做法：直接运行该 JS 求解器导出点集**，不手工翻译。

### 3.2 椭圆中性线变形（Eq.8）

```
a = rp + w0
b = (1/9)[(12rp − 7a) + 4√(a(3rp − 2a))]     # 中点不可伸长
rho(ψ) = ab / √(a²sin²ψ + b²cos²ψ)
w(ψ)   = rho − rm                             # 径向位移
mu(ψ)  = −atan(rho'/rho)                      # 截面转角
v(ψ)   = −(w0/2)·sin(2ψ)                      # 切向位移（一阶）
```

**b 必须 clamp 正数**，否则 w0/rp>0.71 时椭圆翻转。

### 3.3 摆线齿廓（Eq.11）

```
xd = m(t − sin t)/4,  yd = m(1 + cos t)/2
```
- **crest 在 t=π**（圆头，平坦端），**cusp 在 t=0**（节线上，切线径向）
- 方向搞反会出现"方形肩部"（中间鼓起一段水平切线）

**齿形角截断**（论文 §3.3）：t 范围是 **tE→π**，不是 0→π。
`tE` 由 `tan(alpha0) = s0·sin(t)/(ha·(π−t+sin t))` 二分求解。
`toothAngle=0` 退化为未截断曲线（带 cusp）。

### 3.4 7 个必须保留的修正

| # | 修正 | 不修的后果 |
|---|---|---|
| 1 | 摆线方向（crest 在 t=π） | 齿形出现"台阶肩" |
| 2 | 齿形角截断 tE→π | 节线处留尖点 |
| 3 | **截面旋转用 +mu**（局部系是左手系） | 所有齿歪 2mu（可达 4.6°） |
| 4 | 摆线不加齿顶圆弧（crest 本身圆） | 切掉共轭齿面 |
| 5 | **齿根平台也扫进包络** | 长轴处刚轮齿顶啃进柔轮齿根 218µm |
| 6 | 极坐标放置统一（R+y, x/rp） | 齿根角部错 13µm |
| 7 | 齿廓采样 ≥48 点 | 30° 折角 + 14µm 弦差 |

### 3.5 刚轮齿槽 = 包络

柔轮齿在椭圆变形下扫过**一个啮合周期**，取每个角度 bin 的 **max radius**。
- `dz = zc − zf`，`phiMax = π/2/(1+dz/zf)`
- 扫掠步数 800，bins 256
- 齿顶下限 `rFloor = rho(π/2) + ha + clr`，用**软 max** 混合（硬 clamp 会留尖点）

### 3.6 关键数字（CSF-25 实测）

| 项 | 值 |
|---|---|
| zf/zc | 200/202 |
| 传动比 | −100（= zf/(zc−zf)） |
| w0 | 0.8m = 0.2mm |
| 变形后长轴齿顶 | 25.4491（理论 25.450） |
| 变形后短轴齿根 | 24.5493（理论 24.5492） |
| 啮合齿数 | 29/202 (14.5%) |
| 齿侧间隙 | 0.0164mm |

## 四、齿廓进 SolidWorks 的落地

| 场合 | 做法 |
|---|---|
| 单齿槽 + 圆周阵列 | 草图 6 段实体（根弧+左样条+封口线+封口弧+封口线+右样条） |
| 全齿廓一次拉伸 | 点数控制在 2000~5000（4310 点可接受） |
| 柔轮薄壁 | 外轮廓+内孔画在**同一草图**，一次拉伸成环 |
| 椭圆凸轮 | 参数方程 360 点闭合折线 |

**必须**：`with V.addtoDB(m)`、`V.circle`（传圆周点）、`V.extrude_checked`（自动选草图）。

## 五、齿形选择建议

| 场景 | 推荐 |
|---|---|
| 教学/面试作品 | 渐开线包络（行星）+ CTP 摆线（谐波），都有论文/标准依据 |
| 快速可视化 | 渐开线近似 + 高采样 |
| 生产 | 必须确认齿制、变位、侧隙、公差、修形，工程师复核 |

**不要**把"高采样密度"当作"无成本默认"：弧段越多，SW 建模/导出/B-Rep 遍历越慢。
