# 建模工作流与验收纪律

## 一、8 步标准流程

```
① 坐标契约   原点/正方向/主轴/角度零点/重复件相位 —— 写下来，不中途改
② 参数表     参数 | 符号 | 值 | 单位 | 来源 | 用于 | 验证方法
③ 验收矩阵   需求 | 证据 | 通过条件（建之前写死）
④ 能力检查   本机验证过吗？没验证先写最小探针
⑤ API 查证   长参数/枚举/接口归属 → grep 类型库
⑥ 建模       主基准 → 凸台 → 切除 → 阵列 → 圆角 → 外观
⑦ 校验       体积 + bbox + 特征树 三重断言
⑧ 出图交付   四视图 → 目视 → 建完即存、存完即截、截完即关
```

## 二、坐标契约（建模前必须定）

★★ **先查基准面映射表**（本机实测，写错必得躺倒的模型）：

| 基准面 | 草图 x → 世界 | 草图 y → 世界 | 拉伸方向 |
|---|---|---|---|
| **Front** | X | **Y** | **+Z** |
| **Top** | X | **−Z** | **+Y** |
| **Right** | **−Z** | Y | **+X** |

**本机 Y 才是"上下"方向，不是 Z。** 世界点 (x,y,z) 反推草图坐标：
Front→(x,y)、Top→(x,−z)、Right→(−z,y)。不确定就跑 `scripts/probe_axes.py`。

| 项 | 示例（电机支架） |
|---|---|
| 全局原点与正方向 | 底板中心为原点，**Y 向上** |
| 主轴 | 电机轴线沿 **Z**（垂直于立板） |
| 轴向叠层基准面 | 底板下表面 y=0 |
| 角度零点与旋向 | +X 为零点，逆时针为正 |
| 组件插入原点 | 零件自身坐标系即最终姿态 |
| 重复件相位 | 3 行星轮 120° 均布，自转 186.667° |

**单位在边界换算一次**：进 COM 前 `*0.001`（mm→m），出 COM 后 `*1e9`（m³→mm³）。

**旋转轴**：`CreateCenterLine` 全 6 参单位是**米**；轴**必须沿草图 Y 方向**，
轮廓按「X=半径、Y=轴线」画。画成「X=轴线」会绕错轴，体积偏差可达 768%。

## 三、验收矩阵（建之前写）

| 需求 | 证据 | 通过条件 |
|---|---|---|
| 尺寸正确 | 解析体积 vs SW 实测 | 偏差 <0.5% |
| 位置正确 | bbox6 逐项 | ±0.5mm |
| **圆心/轴心正确** | `axial_center_of` / `Transform2` 平移 | **±0.05mm**（旋转件必须验圆心，不能只验 bbox） |
| 无垃圾特征 | 特征树遍历 | 只有预期特征 |
| 装配正确 | 位姿快照比对 | dev <1mm |
| **无干涉** | `interference_verdict(asm)` | **status == "clean"**（`(None,None)` 判 unknown，不算通过） |
| **配合真生效** | 同心配合后测轴心距 | **<0.05mm**（`count_mates` 只证明"被记录"） |
| 啮合正确 | 多边形重叠面积 | 重叠≈0 且间隙=0 |

★ **两条判据边界**（2026-11-22 GR-90 审查实证，见 pitfalls V2/V4）：
- `interference_ok` 旧版把 `(None, None)` 当无干涉 → 全固定装配穿入 10.33mm 也放行。
  现在 `(None,None)` 判 `unknown`（BLOCKED）。**无法验证 ≠ 通过。**
- `max_drift == 0` 在「先 fix_all 再加配合」流程下**恒为 0**，
  与装配对错无关 —— 它只证明"配合没引起移动"，不证明"装配正确"。

**没有可观测证据的需求，不算验收标准。**

## 四、三重断言（不只看一个数）

```python
V.verify(m, volume=理论值, bbox=期望bbox, bodies=1)
```
1. **体积** —— 查"材质多少"，相对偏差 <0.5%
2. **bbox** —— 查"在哪"，逐项 ±0.5mm
3. **特征树** —— 查"留了什么垃圾"

装配额外加：
```python
before = V.snapshot(asm)   # 操作前
# ... 插入/配合 ...
V.diff_snapshot(before, V.snapshot(asm))   # dev>=1mm 拒绝保存
```

## 五、建模顺序（减少拓扑断裂）

```
主基准体 → 功能凸台/筋 → 功能切除/孔 → 阵列 → 圆角倒角 → 外观
```

**引用基准面/轴/原点/命名草图，不引用后面会被切掉的面。**

零件类型策略：
- 轴对称 → 旋转（设计意图重要时）；薄壁回转件画带壁厚闭合截面一次 revolve，别 solid+shell
- 棱柱 → 草图+拉伸+切除
- 变截面 → 放样（截面在平行平面，用 offset_plane 建面）
- 沿路径 → 扫描（轮廓平面垂直路径起点，路径 mark=4）
- 薄壁盒 → 抽壳（平面端面 Select4+mark=1；诊断在选面前做）
- 重复 → 单种子+圆周阵列（轴 mark=1 特征 mark=4，间距传总角度 2π）
- 对称 → 镜像（**特征 mark=1、面 mark=2**；旧文档写反，2026-11-20 实测纠正）
- 轮廓驱动 → 闭合样条，验证闭合与自交
- 外购件 → 保留供应商身份，不重画

★ 非拉伸手法的完整参数/选择集/mark 见 `references/features.md`。

## 六、窗口与文件纪律

- 每次 `NewDocument` 失败/崩溃都会留窗 → **建完即存、存完即截、截完即关**
- 残留窗占满 8 个文档名额
- 所有 save/export **回读文件大小**，0 字节 = 失败
- 已保存文档改动前备份到 `%LOCALAPPDATA%\dsh-solidworks\backups`

## 七、结果自审查

每次生成/修改后：

1. 检查每个 COM 返回值（None / False / 状态码）
2. `ForceRebuild3(False)` + `ViewZoomtofit2()`
3. 导出 iso/front/top/right 四视图
4. **目视检查**：主体存在、比例方位合理、无缺失/重叠/悬空
5. 发现问题先修再汇报，不要只报"保存成功"

## 九、模型状态分级（交付时必须声明）

| 级别 | 含义 |
|---|---|
| 概念 | 几何表达布置，允许假定间隙 |
| 工程布置 | 主尺寸/配合/接口权威，制造细节可能不全 |
| 生产权威 | 公差/材料/配合/可制造性/分析均已复核 |

**没有最后一级的证据，不许称为生产就绪。**
